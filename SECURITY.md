# Política de seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades, credenciales ni datos sensibles en Issues.

Envía el reporte de forma privada a **contacto@gocreative.cl** con:

- Repositorio o sistema afectado.
- Descripción clara del problema.
- Pasos mínimos para reproducirlo.
- Impacto potencial.
- Evidencia técnica sin datos personales de terceros.

Confirmaremos la recepción y coordinaremos una solución responsable. No divulgues el hallazgo hasta recibir autorización de GO Creative.

## Alcance

Esta política aplica a los repositorios mantenidos por GO Creative. La disponibilidad de soporte y actualizaciones depende del contrato y ciclo de vida de cada proyecto.
