# Código de conducta

GO Creative promueve una colaboración profesional, respetuosa e inclusiva.

## Comportamiento esperado

- Comunicarse con respeto y claridad.
- Entregar críticas técnicas constructivas.
- Respetar la privacidad, propiedad intelectual y confidencialidad.
- Evitar discriminación, hostigamiento, amenazas o lenguaje ofensivo.
- Resolver diferencias mediante evidencia técnica y objetivos del proyecto.

## Aplicación

Las conductas contrarias a estas normas pueden implicar eliminación de contenido, revocación de acceso o término de la colaboración.

Para informar una situación de manera confidencial, escribe a **contacto@gocreative.cl**.
