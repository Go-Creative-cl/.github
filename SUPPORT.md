# Soporte

## Consultas comerciales y soporte contratado

Visita [gocreative.cl](https://gocreative.cl) o escribe a **contacto@gocreative.cl**.

## Problemas técnicos

- Usa el formulario de error del repositorio cuando el proyecto permita Issues.
- Incluye versión, entorno, pasos para reproducir y resultado esperado.
- No publiques credenciales, datos personales ni información de clientes.

## Seguridad

Las vulnerabilidades deben reportarse de forma privada siguiendo [SECURITY.md](SECURITY.md).
