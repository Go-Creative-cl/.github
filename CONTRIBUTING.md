# Guía de contribución

Gracias por contribuir a los proyectos de GO Creative.

## Flujo de trabajo

1. Crea una rama desde `main`.
2. Usa nombres claros: `feature/`, `fix/`, `docs/` o `chore/`.
3. Realiza cambios pequeños y enfocados.
4. Ejecuta pruebas, análisis y compilación cuando correspondan.
5. Abre un Pull Request usando la plantilla oficial.
6. Espera la revisión antes de fusionar.

## Estándares

- No incluyas contraseñas, tokens, bases de datos ni archivos `.env`.
- Mantén compatibilidad con la arquitectura existente.
- Documenta cambios de configuración o migraciones.
- Incluye evidencias de prueba y capturas cuando el cambio sea visual.
- Usa mensajes de commit claros y descriptivos.

## Conducta

Toda colaboración debe respetar el [Código de conducta](CODE_OF_CONDUCT.md) y la [Política de seguridad](SECURITY.md).
