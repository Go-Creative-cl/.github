# Estándares de GitHub de GO Creative

Este repositorio contiene el perfil público y las políticas predeterminadas para los proyectos de **GO Creative**.

## Contenido

- `profile/README.md`: presentación pública de la organización.
- `SECURITY.md`: reporte responsable de vulnerabilidades.
- `CONTRIBUTING.md`: flujo y requisitos para contribuciones.
- `CODE_OF_CONDUCT.md`: normas de colaboración.
- `SUPPORT.md`: canales y alcance del soporte.
- `.github/PULL_REQUEST_TEMPLATE.md`: control de calidad para Pull Requests.
- `.github/ISSUE_TEMPLATE/`: formularios estructurados para errores y mejoras.
- `.github/CODEOWNERS`: propiedad del repositorio institucional.

GitHub utilizará los archivos comunitarios compatibles como valores predeterminados en los repositorios públicos de la organización que no tengan una versión propia.

> Los repositorios de clientes deben mantenerse privados. Nunca se deben confirmar credenciales, archivos `.env`, bases de datos reales ni datos personales.
